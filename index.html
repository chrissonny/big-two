規則

  • 四人各 13 張，逆時鐘出牌。持有 ♣3 的人先出，第一手必須包含 ♣3，不能過。
  • 點數大小：3 < 4 < … < K < A < 2；花色大小：♣ < ♦ < ♥ < ♠。點數相同時比花色。
  • 牌型由小到大：單張、一對、順子、葫蘆、鐵支、同花順、一條龍。沒有三條和同花。
  • 順子由小到大：A2345 < 34567 < … < 10JQKA < 23456；JQKA2 不算順子。五張全同花色就是同花順。
  • 鐵支、同花順、一條龍是三大牌，可以壓任何牌型（鐵支<同花順<一條龍，三大牌互相比大小）；其餘牌型只能在同種牌型裡面比大小。
  • 鐵支是四張同點數加任一張單牌。一條龍是 3 到 2 共 13 張；兩條一條龍相碰時，全同花色者較大。
  • 過了就不能再出，要等這一輪結束。其他人都過之後，最後出牌的人重新自由出牌。
  • 頂大：下家只剩一張時，出單張必須出你手上最大的那張。如果你這輪已經過了，限制往前移到還能出牌的人。
  • 計分：輸家剩幾張就是基本分，以下各項累乘：剩 10 張以上 ×2；老二未出每張 ×2（1 張 ×2、2 張 ×4…）；鐵支未出 ×2；同花順未出 ×2（同一張牌不重複算）。
  • 贏家用老二收尾（單張 2、一對 2、23456、2 的葫蘆）、鐵支收尾、同花順收尾或一條龍，每位輸家再 ×2。
  • 🎵 音樂：第一次點擊畫面後會開始播放背景音樂；點右上角 🎵 開關背景音樂、🔊 開關音效。打出鐵支、同花順、一條龍、含老二的牌時會有特殊動畫和音效。

操作：點牌或用手指滑過多張牌來選取，再按「出牌」。上方的牌型按鈕（一對、順子、葫蘆、鐵支、同花順）會挑出可以出的組合，重複按會由小到大換下一組。「提示」會建議最適合出的牌。每回合 20 秒，時間到會自動代打：跟單張時出最小能出的單張，其他牌型自動過。
