# 大老二 Big Two

給 iPhone 直式螢幕玩的四人大老二：你對三個電腦玩家。單一 HTML 檔，不需要安裝或建置。

## 怎麼玩

- 線上版：https://chrissonny.github.io/big-two/
- 用 iPhone Safari 打開後，按「分享 → 加入主畫面」，就能像 App 一樣從桌面開啟。
- 本機：直接用瀏覽器打開 `index.html`。

## 規則

參考神來也大老二的官方規則：

- 持有 ♣3 的人先出，第一手必須包含 ♣3。逆時鐘出牌。
- 點數 3 < … < K < A < 2；花色 ♣ < ♦ < ♥ < ♠。
- 牌型：單張、一對、順子、葫蘆、鐵支（四張加一張單牌）、同花順、一條龍。沒有三條和同花。
- 順子由小到大：A2345 < 34567 < … < 10JQKA < 23456；JQKA2 不算順子。
- 鐵支、同花順可以壓單張、一對和比它小的五張牌型；一條龍壓所有牌型。
- 過了就不能再出，要等這一輪結束。
- 頂大：下家只剩一張時，出單張必須出手上最大的牌。
- 計分：輸家剩餘張數為基本分，累乘：剩 10 張以上 ×2、每張未出的 2 ×2、鐵支未出 ×2、同花順未出 ×2；贏家以老二、鐵支、同花順或一條龍收尾再 ×2。

總分存在瀏覽器的 localStorage，可在「選單」歸零。
